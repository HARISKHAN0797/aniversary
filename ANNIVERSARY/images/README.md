# 📸 Anniversary Website — Photo Guide

Place your family photos in this folder using these exact file names:

| File Name       | Step | Description                        |
|-----------------|------|------------------------------------|
| step1.jpg       |  1   | Early photo — how they first met   |
| step2.jpg       |  2   | Wedding photo                      |
| step3.jpg       |  3   | Family photo (with children)       |
| step4a.jpg      |  4   | Memory photo 1 (gallery)           |
| step4b.jpg      |  4   | Memory photo 2 (gallery)           |
| step4c.jpg      |  4   | Memory photo 3 (gallery)           |
| step5.jpg       |  5   | Latest/recent family photo         |

## Tips:
- Supported formats: .jpg, .jpeg, .png, .webp
- Recommended size: at least 800×600 pixels
- The website will show a placeholder until you add the photo
- You can rename existing photos to match the names above
